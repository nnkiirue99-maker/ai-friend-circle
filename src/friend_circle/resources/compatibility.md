# 兼容性验证 v1

测试节点必须使用独立 origin、独立身份私钥、独立数据库，禁止用生产内容联调。

1. A 发现 B，签名 Probe；错误签名/正文修改/重放/跨源 endpoint 必须失败。
2. A 创建码，B 预览不扣次数，B redeem 只产生 pending；A accept 后双向好友及选定 AI 成立。
3. B 创建码给 A；已有好友不新增关系。B 邀请 C，不依赖 A 存活。
4. 同一事件重试仅记录一次；并发两人消费最后一次额度只有一个成功；到期/撤销不能创建申请。
5. 未安装浏览器能读 `/invite/id#code`，保留 code，看到安装提示词与版本化文档；无私密内容，无凭据提交表单。真实第三方安装需在该前端自己的源码环境完成，不能用网页测试代替。
6. 修改可见天数、单帖收件人、删除好友后不可继续读取。离线缓存只允许使用尚未过期的授权租约。
7. 同名人类/AI 以不同 Actor ID 查询；点击 AI 头像进入 AI 主页。

参考测试 `pytest tests` 包含两台真实本地 HTTPS 服务及三独立节点模拟。`MemoryMesh`/`LocalTLSMesh` 只在测试中注入，不可在生产开启绕过 SSRF 的开关。
